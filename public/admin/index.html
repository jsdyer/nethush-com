Measurement rules

NO THIRD-PARTY ANALYTICS

COUNTS WITHOUT IDENTITIES

There is no visitor table.

A request becomes an increment in a daily counter. There are no raw visit or event rows to anonymize later. We do not hash, shorten or store visitor IP addresses.

We keep

  • UTC date, allowlisted counter name and a total.
  • Latest status, time, duration and bytes for each public feed.
  • Your site settings and an administrator action log.

We do not collect

  • IPs, location, user agents or fingerprints.
  • Visitor IDs, tracking cookies or cross-device data.
  • Referrers, search terms, URLs being inspected or uploaded files.
  • Article clicks, reading shelves or chosen sources.

Turning this off stops new application counters. Feed health continues to show operational status. Existing totals remain until retention expires or you erase them.

Default: 90 days. Old rows are pruned on subsequent activity and whenever the dashboard is read or settings are saved. Lowering retention immediately removes older totals.

Limits and hosting logs

Global Privacy Control and Do Not Track suppress visitor activity counters. No beacon is sent when the browser signals either preference. Feed-service counters describe server operations independently of visitor preferences.

Counts may include bots, your testing and fabricated requests. We do not identify visitors to deduplicate them or profile bots. Section-count writes have a global cap of 600 per minute; excess counts are dropped.

Network connections still expose an IP to the host, CDN or reverse proxy. This application does not read or persist it for measurement. Infrastructure logs must be configured separately. See docs/ADMIN.md for Apache guidance. Database backups may retain deleted totals until those backups expire.

Administrator authentication is separate: self-hosted admin sessions use a necessary HttpOnly cookie, a hashed session token and an expiry. Hosted administration uses the platform sign-in and an explicit owner allowlist. These credentials never enter visitor statistics. Admin action timestamps are retained for 90 days.

Maintenance

EXPORTABLE. INSPECTABLE.

Take your data with you

Export the selected statistics window as JSON or CSV. Configuration export contains only the reader settings, not passwords, sessions or visitor data.

For a complete server backup, back up SQLite using its backup API (or D1 through the hosting platform). Dashboard exports are not authentication backups.

Erase aggregate statistics

Removes every stored daily counter. Site settings, latest feed health and admin audit entries are kept. Export first if you need the totals.
